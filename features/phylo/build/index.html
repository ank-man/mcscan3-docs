    mcscan3 phylo build¶

    NJ and ML trees from CDS (mcscan3 phylo build; legacy apps.phylo build).

    Group phylo · status parity-verified

    Synopsis¶

    mcscan3 phylo build [OPTIONS] FILES...

    Description¶

    Steps, all with external programs:

    1. translate the CDS (unless a protein file is given) and align the proteins with MUSCLE (default) or ClustalW (--msa);
    2. back-translate to a codon alignment with PAL2NAL;
    3. remove poorly aligned blocks with Gblocks (--nogblocks to skip; then --synonymous or --fourfold keep only those sites);
    4. a bootstrapped neighbour-joining tree with EMBOSS PHYLIP (fseqboot, fdnadist, fneighbor, fconsense, ffitch; --noneighbor to skip);
    5. a maximum-likelihood tree with RAxML or PhyML (--ml=raxml|phyml).

    Files go to <outdir>/alignment and <outdir>/tree (<cds prefix>.NJ.unrooted.dnd, <cds prefix>.ML.unrooted.dnd):

    mcscan3 phylo build family0.cds --ml=phyml

    --outgroup=<file> roots the trees on the first outgroup name (prefix) found; --SH=<tree> runs RAxML's SH test against a reference tree; --treefix (with --stree, --smap) runs TreeFix on the RAxML tree. Rooting and the NJ tree need the phylo extra (ete4).

    Differences from the original (docs/DEVIATIONS.md A.11): it crashed on Python 3 when reading Gblocks output, and did not find the -gb.fa file that current Gblocks builds write.

    Arguments¶

    Argument Description
    FILES [prot.fasta] cds.fasta

    Options¶

    Option Description
    --longest Use the longest ORF (no protein file, e.g. ESTs).
    --nogblocks Do not edit the alignment with Gblocks.
    --synonymous Keep synonymous sites only (with --nogblocks).
    --fourfold Keep fourfold degenerate sites (with --nogblocks).
    --msa Protein aligner: clustalw or muscle. (default: muscle)
    --noneighbor Do not build the NJ tree.
    --ml ML tree program: raxml or phyml.
    --outgroup File with outgroup names, in order of preference.
    --SH, --sh Reference Newick tree for the SH test.
    --shout SH output file name. (default: SH_out.txt)
    --treefix Rearrange the ML tree with TreeFix.
    --stree Species Newick tree (TreeFix).
    --smap gene_name_patternspecies_name file (TreeFix).
    --outdir Output directory. (default: .)

    Worked example¶

    Run on real data in the MCscan3 showcase (all commands on published genomes, in workflow order). The command line, console output, output files and figures below are those of that run.

    NJ and maximum-likelihood trees of one family (MUSCLE, PAL2NAL, Gblocks, PHYLIP, PhyML).

    cd phylo && f=$(grep -c '>' sequences/*.cds | awk -F: '$2==4 && !f{print $1; f=1}') && cp $f family.cds  && mcscan3 phylo build family.cds --ml phyml && ls

    run time 2.2 s · data real · showcase step phylo_build
