    Command reference¶

    Every command of MCscan3, grouped as on the command line (mcscan3 <group> <command>). Each page is written from the command's own documentation and options, so it matches -h.

    Status: parity-verified (output identical to JCVI on the test genomes), ported, new (new in MCscan3, no JCVI counterpart; the page cites the method), legacy-only (kept for old command lines).

    prep: Input preparation¶

    Command Status Description
    mcscan3 prep gff2bed parity-verified Convert GFF3 features (e.g. mRNA) to BED, optionally one transcript per gene
    mcscan3 prep fasta-format parity-verified Reformat FASTA and clean up sequence IDs
    mcscan3 prep genome new Longest-isoform BED, CDS and protein from a genome GFF3 and FASTA
    mcscan3 prep bed-merge parity-verified Concatenate BED files, prefixing seqids with the file name
    mcscan3 prep bed-uniq parity-verified Remove overlapping BED features, keeping the best one per pile

    align: Homology search¶

    Command Status Description
    mcscan3 align last parity-verified Align query against a database with LAST (default MCscan aligner)
    mcscan3 align blast parity-verified Align with BLAST+ (blastn megablast, or blastp for proteins)
    mcscan3 align diamond parity-verified Align proteins with DIAMOND blastp
    mcscan3 align mmseqs new Search proteins or CDS with MMseqs2 (BLAST tabular output for synteny)
    mcscan3 align many new Search many genomes in one run (optionally on a GPU); one .last file per pair

    filter: Hit filtering¶

    Command Status Description
    mcscan3 filter blastfilter parity-verified Remove tandem duplicates and low C-score hits from a BLAST table
    mcscan3 filter cscore parity-verified Compute C-scores (score relative to the best hit of either gene)
    mcscan3 filter best parity-verified Keep the best N hits per query (or subject)
    mcscan3 filter rbbh parity-verified Find reciprocal best BLAST hits

    synteny: Synteny block detection and manipulation¶

    Command Status Description
    mcscan3 synteny scan parity-verified Find syntenic anchors by single-linkage clustering of BLAST hits
    mcscan3 synteny summary parity-verified Summary statistics for pairwise synteny blocks
    mcscan3 synteny liftover parity-verified Recruit extra anchors from BLAST hits near existing anchors
    mcscan3 synteny mcscan parity-verified Stack synteny blocks on a reference genome (MCscan-style tracks)
    mcscan3 synteny mcscanq parity-verified Query multiple-synteny blocks for given genes
    mcscan3 synteny query parity-verified Collect syntenic regions matching a query region
    mcscan3 synteny assemble parity-verified Build a blocks file from regions given by start and end genes
    mcscan3 synteny screen parity-verified Extract a subset of blocks from an anchors file
    mcscan3 synteny simple parity-verified Convert anchors to block-end (.simple) descriptions
    mcscan3 synteny stats parity-verified Statistics for MCscan-style blocks files
    mcscan3 synteny depth parity-verified Synteny depth of each genome in a pairwise comparison
    mcscan3 synteny breakpoint parity-verified Identify breakpoints where collinearity ends
    mcscan3 synteny matrix parity-verified Oxford grid (chromosome x chromosome anchor counts)
    mcscan3 synteny from-coge parity-verified Convert a CoGe SynMap file to an anchors file
    mcscan3 synteny from-spa parity-verified Convert SPA chromosome orderings to simple lists
    mcscan3 synteny layout parity-verified Order the chromosomes of a second genome from pairwise blocks
    mcscan3 synteny rebuild parity-verified Rebuild an anchors file from a prebuilt blocks file
    mcscan3 synteny from-aligns parity-verified Convert an old MCScan .aligns file to an anchors file
    mcscan3 synteny to-aligns parity-verified Convert an anchors file to a tab-separated aligns file
    mcscan3 synteny decay new Decay of synteny with divergence: block N50 and coverage against anchor identity, for many genome pairs
    mcscan3 synteny anchor new Synteny-constrained anchors: tandem arrays collapsed, gene-rank chains, buffer rescue, secondary blocks
    mcscan3 synteny convert new Write synteny blocks in other tools' formats (MCScanX, WGDI, GENESPACE, i-ADHoRe, SynVisio, BEDPE, ...)

    quota: Ploidy-constrained block screening¶

    Command Status Description
    mcscan3 quota align parity-verified Screen blocks under a ploidy quota (e.g. 1:2) by integer programming

    ortholog: Ortholog pipelines and catalogs¶

    Command Status Description
    mcscan3 ortholog run parity-verified One-command pipeline: align, filter, scan, liftover (MCscan tutorial)
    mcscan3 ortholog tandem parity-verified Identify tandem gene clusters
    mcscan3 ortholog group parity-verified Cluster anchors into ortholog groups
    mcscan3 ortholog omg-prepare parity-verified Prepare weights for the Sankoff OMG algorithm
    mcscan3 ortholog omg parity-verified Write OMG algorithm inputs per gene family
    mcscan3 ortholog omg-parse parity-verified Parse OMG outputs into gene lists
    mcscan3 ortholog enrich parity-verified Enrich OMG output with genes OMG missed
    mcscan3 ortholog layout parity-verified Lay out ortholog gene lists in columns
    mcscan3 ortholog hogs new Hierarchical orthologous groups at every node of a species tree, guided by synteny
    mcscan3 ortholog soi new Keep orthologous synteny: blocks whose anchors are mostly orthologs (Orthology Index)
    mcscan3 ortholog qc new Orthogroup quality: assignment, species overlap, sizes, domain homogeneity and dispersal, genomes, agreement

    ks: Synonymous substitution rates¶

    Command Status Description
    mcscan3 ks prepare parity-verified Pair CDS sequences for Ks calculation
    mcscan3 ks kaks new Ka, Ks and Ka/Ks of gene pairs with MCscan3's own estimators (no PAML)
    mcscan3 ks calc parity-verified Calculate Ks/Ka for sequence pairs (MSA + PAL2NAL + yn00)
    mcscan3 ks batch parity-verified Write a Makefile computing Ks for several anchors files
    mcscan3 ks from-groups parity-verified Flatten gene families into pairs per species pair
    mcscan3 ks subset parity-verified Subset precomputed Ks values by a pairs/anchors file
    mcscan3 ks gc3 parity-verified Remove high-GC3 genes from Ks results
    mcscan3 ks report parity-verified Report Ks distribution statistics (text)
    mcscan3 ks multireport parity-verified Plot several Ks distributions in one figure

    fractionation: Gene loss after duplication¶

    Command Status Description
    mcscan3 fractionation loss parity-verified Extract gene-loss candidates between two genomes
    mcscan3 fractionation validate parity-verified Confirm synteny loss against CDS overlaps
    mcscan3 fractionation summary parity-verified Summarise fractionation results
    mcscan3 fractionation gaps parity-verified Check gene-loss locations against assembly gaps
    mcscan3 fractionation gff-select parity-verified Select GFF models for missing genes
    mcscan3 fractionation gene-status parity-verified Tag genes by translation status of GMAP models
    mcscan3 fractionation offdiag legacy-only Find off-diagonal gene pairs
    mcscan3 fractionation diff parity-verified Size difference of pairwise syntenic regions
    mcscan3 fractionation napus legacy-only Gene loss vs diploid ancestors (B. napus)
    mcscan3 fractionation merge legacy-only Merge protein quartets with registry (B. napus)
    mcscan3 fractionation segment legacy-only Merge adjacent gene loss into segmental loss (B. napus)

    ancestral: Ancestral genome reconstruction¶

    Command Status Description
    mcscan3 ancestral collinear parity-verified Reduce synteny blocks to strictly collinear chains
    mcscan3 ancestral zipbed parity-verified Build ancestral contigs by interleaving collinear blocks
    mcscan3 ancestral pairs parity-verified Convert an anchors file to a pairs file
    mcscan3 ancestral adjgraph parity-verified Construct a gene adjacency graph (Graphviz)
    mcscan3 ancestral fuse parity-verified Fuse gene orders based on anchors
    mcscan3 ancestral genomes new Reconstruct ancestral gene orders (CARs) at every node of a species tree
    mcscan3 ancestral adjacencies new Ancestral gene adjacencies and CARs over HOGs, dated on the species tree
    mcscan3 ancestral paint new Paint extant chromosomes by the ancestral regions (CARs) they came from
    mcscan3 ancestral karyotype new Group CARs into ancestral chromosomes and paint them on extant karyotypes
    mcscan3 ancestral tree-karyotype new Species tree with a karyotype on every node, and fusion/fission/translocation counts per branch

    pad: Pairwise ancestral decomposition¶

    Command Status Description
    mcscan3 pad cluster parity-verified Segment chromosomes and cluster segments into PADs
    mcscan3 pad pad parity-verified Test and reconstruct candidate PADs

    synfind: Per-gene syntenic region search¶

    Command Status Description
    mcscan3 synfind run parity-verified Find the syntenic region of every gene

    phylo: Trees from MCscan output¶

    Command Status Description
    mcscan3 phylo prepare parity-verified Prepare per-family CDS files from MCscan output
    mcscan3 phylo build parity-verified Build NJ and ML trees from CDS alignments
    mcscan3 phylo draw parity-verified Draw Newick trees
    mcscan3 phylo busco new Phylogenomics from single-copy BUSCO genes: markers, alignments, supermatrix, ML, gene and ASTRAL trees, gCF

    plot: Graphics¶

    Command Status Description
    mcscan3 plot dotplot parity-verified Dot plot of anchors or Ks values
    mcscan3 plot karyotype parity-verified Macrosynteny between genomes drawn as chromosome tracks
    mcscan3 plot microsynteny parity-verified Local synteny of gene-level tracks
    mcscan3 plot chromosome parity-verified Paint features onto chromosomes
    mcscan3 plot ribbon parity-verified Ribbon plot of shared identity between aligned chromosomes
    mcscan3 plot blastplot parity-verified Dot plot of a BLAST table
    mcscan3 plot tree parity-verified Plot a Newick tree with optional annotations
    mcscan3 plot heatmap parity-verified Heatmap from a CSV matrix
    mcscan3 plot histogram parity-verified Histogram of numbers (matplotlib; ASCII mode)
    mcscan3 plot glyph-demo parity-verified Demonstration of gene glyphs
    mcscan3 plot gene-structure parity-verified Draw exon structures of genes from GFF
    mcscan3 plot ks parity-verified Ks distribution histogram (plotting part of ks report)
    mcscan3 plot depth parity-verified Synteny depth histograms
    mcscan3 plot phylo new Tree figures: rectangular or circular, supports and concordance pies, clade shading, aligned data, tanglegrams
    mcscan3 plot riparian new Riparian (braid) plot of synteny across several genomes
    mcscan3 plot dot3d new Three-genome dot plot in 3D, with the pairwise dot plots on the walls of the cube
    mcscan3 plot circos new Circular synteny plot of several genomes, with gene density and ribbons coloured by the reference
    mcscan3 plot locus new Microsynteny of one gene or region across genomes: ribbons, aligned arrows, conservation matrix or dot plots

    dup: Gene duplication modes¶

    Command Status Description
    mcscan3 dup classify new Classify duplicated genes: WGD, tandem, proximal, transposed, dispersed, singleton

    wgd: Whole-genome duplication inference¶

    Command Status Description
    mcscan3 wgd ksd new Whole-paranome or anchor-pair Ks distribution with node weighting
    mcscan3 wgd peaks new Peaks of a Ks distribution (kernel density, bootstrap intervals)
    mcscan3 wgd mix new Mixture models of a Ks distribution: GMM, ELMM, Bayesian GMM (BIC/AIC)
    mcscan3 wgd blocks new Median Ks of each syntenic block (segment-guided Ks)
    mcscan3 wgd correct new Rate-correct a species-divergence Ks onto a focal species' scale
    mcscan3 wgd tree-map new Place gene duplications on a species tree by reconciling gene trees
    mcscan3 wgd consensus new WGDs on a species tree by consensus of block ratio, quota ratio, Ks and gene trees
    mcscan3 wgd transcriptome new WGD signatures from a transcriptome assembly (no genome): ORFs, paranome Ks and mixture models
    mcscan3 wgd compare new Ks distributions of several genomes or transcriptomes as ridgelines, with their WGD peaks

    pan: Pan-genome and multi-genome synteny¶

    Command Status Description
    mcscan3 pan genes new Synteny-constrained pan-gene sets across genomes, placed on a reference
    mcscan3 pan run new Pan-genome two ways, syntenic pan-genes and k-mer sketches of assemblies: classes, curves, Heaps' law

    network: Synteny networks and phylogenomic profiles¶

    Command Status Description
    mcscan3 network build new Build a synteny network from pairwise anchors files
    mcscan3 network cluster new Cluster a synteny network into syntenic loci
    mcscan3 network profile new Species profiles of synteny clusters (counts, PHYLIP)
    mcscan3 network tree new Species tree from synteny-cluster profiles (NJ/UPGMA)
    mcscan3 network stats new Statistics of synteny clusters (density, copies, pan-synteny class), links, modularity
    mcscan3 network gainloss new Where syntenic loci arose and were lost on the species tree (Dollo parsimony)
    mcscan3 network compare new How similar two clusterings are (adjusted Rand index, NMI, splits and merges)
    mcscan3 network plot new Figures of a synteny network: mirrored (raw / phylogeny-corrected) heatmap, profile, graph, cluster

    pipeline: End-to-end runs from a directory of genomes¶

    Command Status Description
    mcscan3 pipeline inputs new Find and prepare the genomes of a directory (raw or processed files)
    mcscan3 pipeline run new Everything from a directory of genomes: orthology, synteny, pan-genes, ancestors, report
    mcscan3 pipeline report new Rebuild the HTML report of a pipeline run from its run.json, without re-running anything

    subgenome: Subgenomes of polyploids: fractionation bias and assignment¶

    Command Status Description
    mcscan3 subgenome fractionation new Biased fractionation of a polyploid against an unduplicated relative (LF / MF copies)
    mcscan3 subgenome assign new Assign the chromosomes of a polyploid to subgenomes by homology (or Ks) to progenitors

    bench: Simulated genomes with known answers, and accuracy scores¶

    Command Status Description
    mcscan3 bench simulate new Simulate gene-annotated genomes along a species tree, with polyploidy, rearrangements and the truth
    mcscan3 bench score new Score anchors against the truth of a simulation (precision, recall, F1)

    annotate: Annotation transfer between assemblies¶

    Command Status Description
    mcscan3 annotate transfer new Transfer gene annotations from related assemblies to a new one, guided by synteny
    mcscan3 annotate chain new Base-level chains between two assemblies from whole-genome alignments
    mcscan3 annotate lift new Lift BED, GFF3/GTF and VCF records to a new assembly through chains

    macro: Macrosynteny of distant genomes: chromosome homology, ancestral linkage groups, fusions¶

    Command Status Description
    mcscan3 macro test new Chromosome pairs of two genomes sharing more gene families than chance (Fisher, FDR)
    mcscan3 macro algs new Ancestral linkage groups found from many genomes (or given), with their chromosomes
    mcscan3 macro fusions new Fusions, fissions and fusion-with-mixing of ALGs per genome; fusion events on the tree
    mcscan3 macro plot new Oxford dot plot of two genomes (ordered by enrichment) or ALG painting of many genomes

    cne: Conserved non-coding elements within syntenic regions and genomic regulatory blocks¶

    Command Status Description
    mcscan3 cne find new Conserved non-coding elements between two genomes, within their syntenic blocks (LAST, one-to-one)
    mcscan3 cne grb new Genomic regulatory blocks: dense clusters of CNEs with synteny kept, merged over comparisons
    mcscan3 cne plot new CNE density along genome a, with GRBs and genes

    micro: Microsynteny blocks of distant genomes: blocks, their origin on the tree, syntenic density¶

    Command Status Description
    mcscan3 micro blocks new Microsynteny blocks: small groups of genes kept together in many distant genomes
    mcscan3 micro nodes new Blocks dated on the species tree: ancestral, novel and lost at every node (Dollo)
    mcscan3 micro density new Syntenic density of the blocks per genome, false blocks from shuffled genomes, transitions on the tree
    mcscan3 micro coexpr new Co-expression of microsynteny block genes against shuffled and random blocks; tau, condition bias, gaps

    wga: Whole-genome alignment of assemblies and DNA-level synteny¶

    Command Status Description
    mcscan3 wga align new Whole-genome alignment of two assemblies (minimap2, base-level CIGAR) to PAF
    mcscan3 wga chain new DNA-level synteny blocks: collinear chains of whole-genome alignments, with a dot plot
    mcscan3 wga windows new Annotation-free synteny: windows of one genome mapped to another and chained into blocks
    mcscan3 wga riparian new Riparian plot of DNA-level synteny along a chain of genomes, phased by a reference

    sv: Structural variants and small variants between assemblies¶

    Command Status Description
    mcscan3 sv call new Syntenic regions, inversions, translocations, duplications, indels and SNPs between two assemblies
    mcscan3 sv plot new Genomes stacked as rows of chromosomes, with syntenic and rearranged regions as ribbons
    mcscan3 sv merge new Merge the variants of many genomes against one reference: pan-SVs, presence, core and variable genome
    mcscan3 sv pan new Structural-variant pipeline over many assemblies: align, call, merge, plot

    introgress: Introgression and haplotype sharing from k-mers of assemblies or reads¶

    Command Status Description
    mcscan3 introgress scan new Introgression and haplotype-sharing scan: k-mer containment of target windows in each source
    mcscan3 introgress plot new Chromosome painting: containment tracks and blocks along every chromosome

    view: Genome and haplotype comparison views: identity along chromosomes, identity matrices, interactive browser¶

    Command Status Description
    mcscan3 view identity new Identity of genomes to a reference in windows: table and heatmap
    mcscan3 view matrix new All-against-all k-mer identity (ANI) of genomes: matrix, pairs and clustered heatmap
    mcscan3 view browse new Interactive HTML browser of alignments, SVs, paintings and identity along a reference
    mcscan3 view tracks new Genome track figures from an INI file: genes, BED, signals, links, microsynteny ribbons

    scaffold: Assembly scaffolding: Hi-C (allele-aware, polyploid), references, genetic maps, contact maps and curation¶

    Command Status Description
    mcscan3 scaffold contacts new Hi-C contacts binned along the contigs (.npz), with the distance-decay exponent
    mcscan3 scaffold hic new Hi-C scaffolding, allele- and haplotype-aware: AGP, FASTA, groups, contact map
    mcscan3 scaffold hicmap new Hi-C contact map of scaffolds (whole genome or selected), log scale, scaffold outlines
    mcscan3 scaffold review new Interactive review page: interactive contact map, curation, AGP/.assembly export
    mcscan3 scaffold apply new Build the scaffolds of an AGP or .assembly: AGP and FASTA
    mcscan3 scaffold ref new Reference-guided correction and scaffolding, several references at once
    mcscan3 scaffold map new Genetic-map scaffolding: split, assign, order, orient
    mcscan3 scaffold run new Scaffolding with references, genetic maps and Hi-C in one graph; joins and conflicts reported

    karyotype: Ancestral karyotypes mapped onto genomes, chromosome fusion and fission events, ancestral genomes¶

    Command Status Description
    mcscan3 karyotype map new Paint a known ancestral karyotype on genomes through synteny blocks (optionally of one Ks event)
    mcscan3 karyotype events new Fusions (EEJ, NCF), translocations and fissions from the ancestral karyotype; shared events on the tree
    mcscan3 karyotype genome new Write the ancestral karyotype as a genome (BED, lens, proteins, CDS) to align and plot against

    go: Gene Ontology: enrichment of MCscan3 gene sets, GO slims and functional similarity of gene pairs¶

    Command Status Description
    mcscan3 go enrich new Gene Ontology enrichment of gene sets (lists, set tables or MCscan3 outputs)
    mcscan3 go sets new Named gene sets from MCscan3 outputs, for enrichment and slims
    mcscan3 go slim new Gene annotations summarised on a GO slim, per gene set
    mcscan3 go similarity new Functional similarity (GO semantic similarity) of gene pairs, by group, against random pairs

    expr: Expression: count matrices, differential expression by Bayes factors, homoeolog bias, pair similarity¶

    Command Status Description
    mcscan3 expr counts new Gene x sample counts, TPM and CPM from featureCounts, htseq, Salmon, kallisto or RSEM
    mcscan3 expr de new Differential expression: genes ranked by Bayes factors, with replicate consistency checks
    mcscan3 expr homoeolog new Homoeolog expression bias and subgenome dominance across conditions
    mcscan3 expr pairs new Expression correlation and divergence of gene pairs; tissue specificity

    gff: GFF3/GTF toolkit: repair, convert, statistics, isoforms, filters, sequences, merging, IDs, comparison¶

    Command Status Description
    mcscan3 gff fix new Check and repair a GFF3/GTF (IDs, parents, exons, UTRs, phases, spans, duplicates)
    mcscan3 gff convert new Convert between GFF3, GTF and BED
    mcscan3 gff stats new Numbers and lengths of genes, transcripts, exons, introns, CDS and UTRs
    mcscan3 gff longest new Keep the longest isoform of each gene
    mcscan3 gff filter new Keep genes by type, location, attributes, length, protein size or exons
    mcscan3 gff extract new Sequences of genes, CDS, proteins, mRNAs, exons, introns, UTRs or flanks
    mcscan3 gff merge new Merge annotations; overlapping genes join, identical transcripts are dropped
    mcscan3 gff rename new Systematic IDs for genes, transcripts and their parts
    mcscan3 gff add new Add introns, UTRs, intergenic regions or start/stop codons
    mcscan3 gff compare new Compare two annotations: loci and sensitivity/precision per level

    project: Project files of MCscan3 runs: show, fetch cached outputs, rerun, history¶

    Command Status Description
    mcscan3 project show new Command, inputs and outputs of a recorded run
    mcscan3 project fetch new Unpack the outputs cached in a project file
    mcscan3 project rerun new Run a recorded command again, restoring cached outputs when inputs are unchanged
    mcscan3 project history new Recent MCscan3 runs from the cache index

    fetch: Genomes and annotations from NCBI, Ensembl, NGDC GWH and CNGB by accession, species or taxon¶

    Command Status Description
    mcscan3 fetch genome new Download genomes and annotations by accession, species or URL from NCBI, Ensembl, GWH, CNGB
    mcscan3 fetch taxon new Best annotated genome of every species of a taxon, listed or downloaded, with a taxonomy tree

    te: Transposable elements: discovery of every order, clade classification, libraries, annotation, ages, LAI¶

    Command Status Description
    mcscan3 te ltr new Intact LTR retrotransposons: TSDs, motifs, LTR identity, insertion ages, nested insertions
    mcscan3 te classify new Clade-level TE classification from protein domains: lineage, Wicker code, domain order, strand, support
    mcscan3 te tir new DNA transposons and MITEs from terminal inverted repeats: TSDs, Wicker superfamily, families, nesting
