    mcscan3 go slim¶

    Gene annotations summarised on a GO slim.

    Group go · status new · new in MCscan3

    Synopsis¶

    mcscan3 go slim [OPTIONS]

    Description¶

    New in MCscan3, after the slim mapping of GOATOOLS (Klopfenstein DV et al. 2018, Sci Rep 8:10872) and map2slim (GO Consortium). Each term of a gene maps to its direct slim ancestors: the slim terms among the term and its ancestors that have no other such slim term below them (--all-ancestors: every slim ancestor). The slim is a separate OBO (e.g. goslim_plant.obo, --slim) or a subset of the main ontology (--subset goslim_plant).

    With gene sets (as for go enrich: --study, --sets, --from) the genes of each set are counted per slim term, as numbers and as shares of the set's annotated genes, next to the population; a grouped bar chart shows the shares per namespace. Writes <prefix>.genes.tsv (gene, slim terms), <prefix>.counts.tsv (slim term, namespace, name, then genes and share per set) and <prefix>.<format>:

    mcscan3 go slim --obo go-basic.obo --slim goslim_plant.obo --annotations ath.gaf \
    --from ath.genes -o ath.dup.slim

    Arguments¶

    Argument Description

    Options¶

    Option Description
    --obo Gene Ontology (OBO, e.g. go-basic.obo; gzip ok).
    --annotations, -a GAF, GPAD, gene2go, eggNOG-mapper, InterProScan or gene-GO table.
    --prefix, -o Output prefix.
    --slim GO slim (OBO), e.g. goslim_plant.obo.
    --subset Or a subset of the ontology, e.g. goslim_plant.
    --all-ancestors Map to every slim ancestor, not only direct.
    --study Gene list or BED of a study set (repeatable; set named after the file). (default: [])
    --sets Named sets: setgene (from go sets).
    --from MCscan3 outputs to take sets from (see go sets; repeatable). (default: [])
    --bed Genes (BED) for region outputs (SVs, introgression) and the population.
    --population Population: gene list or BED (default: from the sets' source).
    --genome Genome column of pan-gene / microsynteny tables.
    --species Species of HOG tables.
    --ann-format auto, gaf, gpad, gpad2, gene2go, emapper, interproscan, table. (default: auto)
    --id-field GAF gene ids: id, symbol or synonym. (default: id)
    --evidence Keep only these evidence codes (repeatable). (default: [])
    --no-evidence Drop these evidence codes, e.g. IEA (repeatable). (default: [])
    --strip Regular expression removed from gene ids, e.g. '.\d+$'.
    --relationships Also propagate through these relations (part_of, regulates, all). (default: [])
    --top Slim terms per namespace in the figure. (default: 15)
    --format Image format. (default: pdf)
    --dpi Dots per inch. (default: 300)

    Worked example¶

    Run on real data in the MCscan3 showcase (all commands on published genomes, in workflow order). The command line, console output, output files and figures below are those of that run.

    Gene sets summarised on the plant GO slim.

    mcscan3 go slim --obo $IN/go-basic.obo -a go/tair.gaf.gz --slim go/goslim_plant.obo --sets go/ath.sets.tsv --strip '\.\d+$' -o go/ath.slim

    run time 1.6 s · data real · showcase step go_slim

    Variables: $IN downloaded showcase inputs.

    Method and references¶
