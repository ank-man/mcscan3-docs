    mcscan3 macro test¶

    Which chromosomes of two genomes descend from the same ancestral chromosome.

    Group macro · status new · new in MCscan3

    Synopsis¶

    mcscan3 macro test [OPTIONS] BED_A BED_B

    Description¶

    New in MCscan3. Between distantly related genomes (hundreds of millions of years), gene order is lost but genes stay on the chromosomes they came from: macrosynteny (Simakov et al. 2020, Nature Ecology & Evolution 4:820; Simakov et al. 2022, Science Advances 8:eabi5884). For every pair of chromosomes, the number of gene families with genes on both is compared with what the chromosome sizes alone would give by the one-sided Fisher exact test, and adjusted for the number of pairs (Benjamini-Hochberg; --adjust bonferroni|holm|none). Families come from an orthogroup table (--families) or from reciprocal best hits in a BLAST table (--hits):

    mcscan3 macro test amphioxus.bed scallop.bed --families Orthogroups.tsv -o amph.scallop

    Writes <prefix>.macro.tsv, one row per chromosome pair: shared families, expected, the ratio, p and adjusted q, and whether the pair is significant (q <= --alpha and at least --min-count families); prints the significant pairs. macro plot --kind oxford draws them.

    Arguments¶

    Argument Description
    BED_A Genes of the first genome (BED).
    BED_B Genes of the second genome (BED).

    Options¶

    Option Description
    --prefix, -o Output prefix.
    --families Orthogroups.tsv or genefamily table.
    --hits BLAST table: families from reciprocal best hits.
    --adjust bh, bonferroni, holm or none. (default: bh)
    --alpha Largest adjusted p of a significant pair. (default: 0.05)
    --min-count Fewest shared families of a significant pair. (default: 3)
    --min-genes Smallest chromosome kept (genes with a family). (default: 20)
    --max-copies Families with more genes in a genome are left out there. (default: 4)

    Worked example¶

    Run on real data in the MCscan3 showcase (all commands on published genomes, in workflow order). The command line, console output, output files and figures below are those of that run.

    Example 1¶

    Grape and A. thaliana chromosome pairs sharing more families than chance.

    mkdir -p macro && mcscan3 macro test $R/data/grape.bed $R/data/ath.bed --families $R/orthology/orthofinder/Results_mcscan3/Orthogroups/Orthogroups.tsv -o macro/grape.ath && head -4 macro/grape.ath*.tsv

    run time 0.6 s · data real · showcase step macro_test

    Variables: $R the eudicot pipeline run (six genomes).

    Example 2¶

    Oxford plot of D. melanogaster against A. gambiae: chromosome arms (Muller elements) conserved over about 250 million years, genes scrambled inside them.

    mkdir -p kingdoms/macro && mcscan3 macro test kingdoms/insects/dmel.bed kingdoms/insects/agam.bed --hits kingdoms/insects/dmel.agam.last -o kingdoms/macro/dmel.agam  && mcscan3 macro plot kingdoms/macro/dmel.agam kingdoms/insects/dmel.bed kingdoms/insects/agam.bed --hits kingdoms/insects/dmel.agam.last

    run time 2.9 s · data real · showcase step kingdoms_macro

    Method and references¶

    New in MCscan3 (no JCVI equivalent). Macrosynteny after Simakov O et al. (2020) Deeply conserved synteny resolves early events in vertebrate evolution. Nat Ecol Evol 4:820; Simakov O et al. (2022) Deeply conserved synteny and the evolution of metazoan chromosomes. Sci Adv 8:eabi5884; Schultz DT et al. (2023) Ancient gene linkages support ctenophores as sister to other animals. Nature 618:110; one-sided Fisher exact tests with Benjamini-Hochberg FDR; reimplemented.
