    mcscan3 synteny convert¶

    Synteny blocks in the format of your choice (mcscan3 synteny convert, --out-format).

    Group synteny · status new · new in MCscan3

    Synopsis¶

    mcscan3 synteny convert [OPTIONS] BLOCKS

    Description¶

    New in MCscan3. Blocks of anchors (MCscan .anchors, MCScanX .collinearity or WGDI collinearity files; read automatically) are written in one or more formats, with the gene coordinates of the two BED files:

    • anchors: MCscan .anchors (### between blocks, gene1 gene2 score);
    • mcscanx: MCScanX .collinearity (## Alignment k: score=... e_value=... N=... chr1&chr2 plus|minus` then `k- i: gene1 gene2 value`) and its four-column `.gff (chromosome, gene, start, end) for both genomes, the inputs of MCScanX's downstream tools and SynVisio;
    • wgdi: WGDI collinearity (# Alignment k: score=... pvalue=... N=... chr1&chr2 plus|minus then gene1 order1 gene2 order2 direction), a block table (blockinfo.csv: id, chromosomes, start and end orders, p value, length, Ks columns filled from --ks when given, the anchor orders block1/block2 and anchor densities density1/density2; the columns homo1-homo5 and tandem_ratio are left empty as they come from WGDI's own BLAST ranking) and WGDI's .gff and .lens for each genome;
    • genespace: GENESPACE's syntenic hits (<g1>_vs_<g2>.synHits.txt.gz: anchors with genome-wide gene orders, isAnchor TRUE and the block id) and syntenicBlock_coordinates.csv (block extents in base pairs and gene orders, first and last genes, orientation);
    • iadhore: i-ADHoRe multiplicons.txt and anchorpoints.txt (gene positions 0-based);
    • synvisio: the MCScanX pair (.collinearity and a .gff of both genomes) named for SynVisio's upload page;
    • bedpe: one line per block, the two block extents in base pairs, name, anchors, strands;
    • tsv: one line per anchor with block, both genes and their coordinates, score and strand.

    Block scores follow MCScanX's defaults (50 per anchor, -1 per gene of gap on the longer side); the p value (MCScanX's e_value, WGDI's pvalue) is MCscan3's: the chance of as many anchors in the block's gene-rank box if the anchors of the chromosome pair were spread uniformly (Poisson). MCScanX writes BLAST e-values in its third column; MCscan3 writes the anchor's score there. Formats after MCScanX (Wang Y et al. 2012, NAR 40:e49), WGDI (Sun P et al. 2022, Mol Plant 15:1841), i-ADHoRe 3.0 (Proost S et al. 2012, NAR 40:e11) and SynVisio (Bandi V, Gutwin C 2020) and GENESPACE (Lovell JT et al. 2022, eLife 11:e78526):

    mcscan3 synteny convert grape.peach.anchors --qbed grape.bed --sbed peach.bed \
    --to mcscanx,wgdi,bedpe -o grape.peach
mcscan3 synteny anchor grape.peach.last --out-format mcscanx,wgdi

    Arguments¶

    Argument Description
    BLOCKS Anchors (.anchors), MCScanX .collinearity or WGDI collinearity file.

    Options¶

    Option Description
    --qbed Query BED (default: .bed from a file named a.b.*).
    --sbed Subject BED (default: .bed).
    --to anchors, mcscanx, wgdi, genespace, iadhore, synvisio, bedpe, tsv (comma-separated). (default: mcscanx)
    --prefix, -o Output prefix (default: the input without extension).
    --from Input format: auto, anchors, mcscanx or wgdi. (default: auto)
    --ks Ks of gene pairs (for WGDI's block table).
    --names Genome names, e.g. grape,peach (default: from the BED files).

    Worked example¶

    Run on real data in the MCscan3 showcase (all commands on published genomes, in workflow order). The command line, console output, output files and figures below are those of that run.

    Blocks written for MCScanX, WGDI, GENESPACE, i-ADHoRe, SynVisio, BEDPE and as a table.

    mkdir -p formats && cd core && mcscan3 synteny convert grape.peach.lifted.anchors --qbed grape.bed --sbed peach.bed --names grape,peach  --to mcscanx,wgdi,genespace,iadhore,synvisio,bedpe,tsv -o ../formats/grape.peach && ls -l ../formats

    run time 1.6 s · data real · showcase step synteny_convert

    Method and references¶

    New in MCscan3 (no JCVI equivalent). MCscan3: blocks of .anchors, MCScanX or WGDI collinearity files written as MCScanX (Wang Y et al. 2012, NAR 40:e49), WGDI (Sun P et al. 2022, Mol Plant 15:1841), i-ADHoRe 3.0 (Proost S et al. 2012, NAR 40:e11), SynVisio, GENESPACE (Lovell JT et al. 2022, eLife 11:e78526), BEDPE or a long table, with gene coordinates from the BED files.
